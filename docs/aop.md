# AOP 编程

跨越应用程序多个模块的公共行为，与业务逻辑关系不大的非核心功能，例如日志、事务、安全。

- **切面 Apect（功能模块）**：对横切关注点的模块化。它是一个类，其中包含了通知和切入点。例如，一个日志切面。
- **连接点 Joinpoint**：程序执行过程中的一个特定点，如方法的调用或异常的抛出。在 Spring AOP 中，连接点总是代表方法的执行。

- **切入点 (Pointcut)** ：一组匹配连接点的表达式。它定义了“在哪里”应用通知，即哪些连接点会被拦截。

- **通知/增强**：切面在特定连接点上要执行的具体代码，即“做什么”。Spring AOP 支持五种类型的通知：
  - **前置通知**：在目标方法执行前调用。
  - **后置通知**：在目标方法执行后调用，无论方法是否抛出异常。
  - **返回通知**：在目标方法成功执行并返回后调用。
  - **异常通知**：在目标方法抛出异常后调用。
  - **环绕通知**：最强大的通知，可以在方法执行前后自定义行为，甚至决定是否执行目标方法。
